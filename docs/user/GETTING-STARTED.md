# Getting started

Manifold is a local notes app for your Mac. Your notes are plain Markdown files in a folder you choose, and everything works on your computer without an account or an internet connection. AI features are optional and are described in [AI & models](AI-AND-MODELS.md).

## Open or create a workspace

When Manifold starts you see the workspace window with three choices:

- **Create workspace…** makes a new notes folder. Before anything is created, Manifold shows you what it will add.
- **Open folder…** turns a folder of existing Markdown notes into a workspace. Obsidian vaults work as they are. See [Import & migration](IMPORT-AND-MIGRATION.md).
- **Try demo** opens a small sample workspace that works offline. See [Demo workspace](DEMO-WORKSPACE.md).

Workspaces you used before are listed under **Recent workspaces**. More about workspaces, including what Manifold stores next to your notes, is in [Workspaces](WORKSPACES.md).

## First-run setup

The first time you open a workspace, a short setup takes you through these steps:

1. **Welcome**: a summary of how Manifold works.
2. **Your workspace**: confirms the folder you opened.
3. **Language of your notes**: optional. The editor recognises the language you are writing by itself, so you can leave this on Automatic. The interface is in English.
4. **Choose your experience**: Student, Knowledge worker, Developer, Research or Custom. This only decides which tools are visible at first; it never changes your notes.
5. **AI when you need it**: AI is optional. Choose **Continue without AI** to start right away.
6. **Privacy and access**: choose what may run in the background. System permissions need your separate approval.

Every choice can be changed later in Settings (⌘,). To see the setup again, open **Settings › General › Run setup again**.

## Write your first note

1. Press ⌘N to create a note. Where new notes go is set in **Settings › Files & links**.
2. Type. Markdown shortcuts such as `#` for a heading or `- ` for a list work as you type, and `/` at the start of a line opens an insert menu.
3. Type `[[` to link to another note. Manifold suggests matching notes as you type.

Manifold saves while you type, so there is no save step. ⌘S saves right away if you want to be sure. The editor is described in [Notes & editing](NOTES-AND-EDITING.md).

## Find your way around

| To do this | Press |
|---|---|
| Run any command by name | ⌘P (command palette) |
| Open or create a note by name | ⌘O (quick switcher) |
| Search the whole workspace | ⇧⌘F |
| Open Settings | ⌘, |
| See running tasks, study progress and models | ⇧⌘M (Manifold panel) |
| Show or hide the left and right sidebars | ⌥⌘1 and ⌥⌘2 |

Every command in the app is available from the command palette, and most can be given a shortcut. The full list is in [Hotkeys](HOTKEYS.md).

## Your notes are protected

- Before each change Manifold keeps a snapshot, so changes can be undone. Open a note's **History** in the right sidebar to look at earlier versions.
- Deleted files go to the macOS Trash.
- If something looks wrong, **Check app health** (Settings › General) reads the state of the installation and offers safe fixes. See [Health & troubleshooting](HEALTH-AND-TROUBLESHOOTING.md).
