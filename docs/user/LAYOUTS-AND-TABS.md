# Layouts & tabs

Manifold lets you keep several notes open at once, side by side or stacked, and save arrangements you like.

## Tabs

| To do this | Press |
|---|---|
| New tab | ⌘T |
| Close tab | ⌘W |
| Reopen the last closed tab | ⇧⌘T |
| Next or previous tab | ⌃Tab and ⌃⇧Tab |
| Go to tab 1 to 8, or the last tab | ⌘1 to ⌘8, and ⌘9 |
| Back or forward through the notes you visited | ⌥⌘← and ⌥⌘→ |

A new tab shows quick actions: create a note, open the daily note, open a file or run a command.

**Pinned tabs.** Use *Toggle tab pin* or the tab menu (right-click a tab) to pin a tab. The commands *Close other unpinned tabs*, *Close unpinned tabs to the right* and *Close unpinned tabs in group* leave pinned tabs open.

## Splits and groups

Tabs live in groups. Split the view to see two notes at once:

- ⇧⌘2 splits to the right.
- *Split down* (⌥⌘↓) splits below. While the cursor is in the editor, ⌥⌘↓ belongs to the editor, so use the command palette there.
- ⌘⌥-click a link, or **Open in split** from the file tree, opens the note in a new group.

Move between groups with *Next pane*, *Previous pane* and *Focus pane to the left / right / above / below*. *Close tab group* closes the active group.

**Linked groups.** *Link tab group…* connects two groups so that opening a note in one opens it in the other too. *Unlink tab group* separates them again.

## Sidebars and the status bar

- ⌥⌘1 shows or hides the left sidebar (Files, Tags, Properties, Search).
- ⌥⌘2 shows or hides the right sidebar (backlinks, outline, history and more).
- The **status bar** at the bottom shows the indexing state, the backlink count, and the word and character count of the note, or of your selection. A button there opens the notification history.
- The **ribbon** is the strip of quick-action icons. Right-click it to hide an icon or move it up or down, or run *Show / hide ribbon*.

Press F6 to move the keyboard focus to the next region of the window, and ⇧F6 to go back.

## Saved layouts

Run *Save workspace layout as…* to store the current arrangement of tabs, groups and sidebars under a name. *Manage workspace layouts* lists the saved layouts, loads one and deletes the ones you no longer want. The number of saved layouts is limited, and a layout with too many tabs is too large to save: close a few tabs first.

## Look and feel

- **Zoom**: ⌘= zooms in, ⌘- zooms out and ⌘0 resets. The editor font size is separate (**Settings › Appearance**).
- **Theme**: System, Light or Dark, in **Settings › Appearance** or from the command palette.
- **Quiet mode**: hides interface elements you do not need while you write. Errors, unsaved changes and a lost connection stay visible. Turn it on with *Quiet mode on/off*.
- **Readable line length** keeps long lines to a comfortable width (**Settings › Editor**).
